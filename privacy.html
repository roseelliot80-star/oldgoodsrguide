Privacy

A readable site without registration or tracking code.

This page describes the static website version researched and prepared on November 21, 2026.

Information you provide

This website has no contact forms, lead forms, account system, comments, newsletter signup, or registration gate. It does not ask you to submit a name, email address, phone number, location, or vehicle-shopping information.

Analytics, advertising, and storage

The site code contains no analytics scripts, tracking pixels, third-party advertising widgets, or behavioral profiling tools. It does not set cookies or use browser local storage. The printable checklist is rendered locally by your browser; printing it or marking a paper copy sends no checklist responses to this website.

External links

Vehicle profiles link to manufacturer websites so you can inspect the supporting sources. When you follow an external link, that website’s own privacy practices apply. Those external services are not embedded as trackers on this site.

Hosting

Like other websites, the published site depends on a hosting provider to deliver its files. Any standard technical server logs maintained by that provider are separate from the static page code described here.

Changes

If forms, analytics, advertising technology, or other data-collection features are added later, this Privacy page should be updated before those features go live.
